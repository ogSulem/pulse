# Pulse — старт без вложений

Цель этого документа: от пустого сервера до первых денег, не потратив ни рубля.
Всё, что описано, действительно бесплатно: бесплатные ключи, бесплатная озвучка,
бесплатные кадры, бесплатный публичный адрес. Платить придётся только за хостинг,
если не брать бесплатный уровень (см. шаг 1).

Порядок важен: каждый следующий шаг опирается на предыдущий.

---

## Шаг 0. Что вы получите

Конвейер, который **сам** каждый день пишет сценарии, озвучивает, рисует кадры,
собирает видео и публикует его в ваши каналы. Ваша роль — раз в несколько дней
посмотреть сводку и поправить то, что Pulse отметил как проблему.

Деньги на старте дают три канала (выплаты площадок требуют условий, которых у нового
канала нет):

1. **свой продукт или услуга** — ссылка в описании, клики и продажи считаются;
2. **партнёрские (CPA) ссылки** — вы получаете комиссию, платформа считает EPC и ROI;
3. **бренд-интеграции** — ручные кампании с оплатой за выход/CPM/CPA.

---

## Шаг 1. Поднять панель (15 минут, 0 ₽)

**Вариант A — свой компьютер или домашний сервер.** Проще всего для старта:

```bash
git clone <репозиторий> pulse && cd pulse
cp .env.example .env
nano .env          # PULSE_PASSWORD, PULSE_SECRET (openssl rand -hex 32), PULSE_MODE=live
docker compose up -d --build
```

**Вариант B — Railway (самый быстрый внешний адрес).** Одна команда, дальше ничего настраивать
не нужно — адрес, HTTPS, пароль и том скрипт сделает сам:

```bash
bash deploy/railway.sh
```

Нюанс денег: Railway не бесплатен постоянно — пробный кредит $5 на 30 дней, затем Hobby $5/мес
(внутри которых $5 использования). Подробности и разбор сбоев — `docs/RAILWAY.md`.

**Вариант C — бесплатный хостинг.** Oracle Cloud Always Free: ARM-инстанс 4 OCPU / 24 ГБ
(бесплатно бессрочно). Подойдёт и любой VPS за 200–300 ₽, если нужен внешний адрес.
Инструкция по шагам — `docs/DEPLOY.md`.

Проверка: откройте адрес панели (в Railway его напечатает скрипт), войдите паролем.
Плашка «Хостинг и диск» в студии покажет, что ещё не настроено, — это и есть чек-лист.

## Шаг 2. Включить ИИ (5 минут, 0 ₽)

Нужен **один** бесплатный ключ. Порядок предпочтения:

| Ключ | Где взять | Лимиты | Комментарий |
|---|---|---|---|
| `NVIDIA_API_KEY` | [build.nvidia.com](https://build.nvidia.com) → Get API Key | ~40 запросов/мин | карта не нужна, модели 70B+, плюс видео Cosmos |
| `GITHUB_TOKEN` | [github.com/settings/tokens](https://github.com/settings/tokens) → fine-grained → `models:read` | ~150 запросов/день | ключ уже есть у любого разработчика |
| `GEMINI_API_KEY` | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | щедрый бесплатный уровень | данные уходят в обучение Google |
| `GROQ_API_KEY` | [console.groq.com/keys](https://console.groq.com/keys) | 30/мин, 1000/день | самая быстрая выдача |

В `.env`:

```
PULSE_AI=on
NVIDIA_API_KEY=nvapi-...
```

Проверка: «Настройки → ИИ-движок → Проверить ИИ живым запросом». Должно ответить
названием модели и миллисекундами.

> Ключи можно добавлять по одному: роутер перебирает провайдеров по цепочке и берёт
> первый доступный. Если один упёрся в лимит — второй подхватит автоматически.

Озвучка отдельного ключа **не требует**: `TTS_PROVIDER=edge` — нейронные голоса
Microsoft (`ru-RU-DmitryNeural` / `SvetlanaNeural`), любая длина, 0 ₽.

## Шаг 3. Публичный адрес (3 минуты, 0 ₽)

> На Railway этот шаг делается сам: адрес приходит из `RAILWAY_PUBLIC_DOMAIN`, и вписывать его
> в переменные не нужно. Профиль `tls` собирает адрес из `PULSE_DOMAIN` — тоже без ручной работы.
> Читать дальше нужно, если запускаете локально или на VPS без домена.

Instagram и TikTok публикуют не файл, а **ссылку**: площадка сама скачивает видео.
Поэтому панель должна быть доступна из интернета. Домен не обязателен:

```bash
bash deploy/tunnel.sh
```

Скрипт скачает официальный `cloudflared` (аккаунт не нужен) и напечатает адрес вида
`https://what-ever-words.trycloudflare.com` плюс готовые redirect URI для кабинетов
разработчика. Впишите адрес в `.env`:

```
PULSE_PUBLIC_URL=https://what-ever-words.trycloudflare.com
```

и перезапустите: `docker compose up -d`.

Проверка: «Студия → Проверить публичный адрес». Проверка идёт **снаружи** и смотрит не
только панель, но и отдачу `/media` — именно туда смотрит Instagram.

> Туннель живёт, пока открыт терминал. Для постоянного адреса — домен и профиль Caddy:
> `docker compose --profile tls up -d`. Свой домен подставляется автоматически, дублировать
> `PULSE_PUBLIC_URL` не нужно.

Проверить, что видит платформа, можно в **Студия → «Хостинг и диск»** или `GET /api/deploy/ready`:
там же будет написано, если адрес не определился и что именно задать.

## Шаг 4. Подключить каналы (10 минут на площадку, 0 ₽)

Кнопка «Войти и подключить» в разделе «Аккаунты» — но сначала нужно один раз создать
приложение площадки. Все площадки бесплатны.

### YouTube (самый простой и самый полезный)

1. [console.cloud.google.com](https://console.cloud.google.com) → создайте проект (бесплатно).
2. **APIs & Services → Library** → включите **YouTube Data API v3**.
3. **OAuth consent screen** → тип External → заполните название и e-mail → добавьте себя
   в **Test users** (этого достаточно, публикация работает).
4. **Credentials → Create credentials → OAuth client ID → Web application**.
   В **Authorized redirect URIs** вставьте: `<PULSE_PUBLIC_URL>/api/oauth/youtube/callback`.
5. Скопируйте Client ID и Client secret в `.env`:

```
YOUTUBE_CLIENT_ID=...
YOUTUBE_CLIENT_SECRET=...
```

6. «Аккаунты → Войти и подключить» → выберите канал → разрешите доступ.

### TikTok

1. [developers.tiktok.com](https://developers.tiktok.com) → Manage apps → создайте приложение.
2. Добавьте продукты **Login Kit** и **Content Posting API**, укажите тот же redirect URI
   с `/api/oauth/tiktok/callback`.
3. В `.env`: `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET` (это `client_key`, не `client_id`).
4. Пока приложение не прошло аудит, TikTok разрешает только приватные публикации:
   переключатель «TikTok-клиент прошёл аудит» в настройках.

> TikTok Creator Rewards работает только в 8 странах и требует 10 000 подписчиков.
> В РФ деньги даёт не выплата площадки, а продукт и интеграции — об этом честно
> написано и в интерфейсе.

### Instagram (Reels)

1. Аккаунт Instagram должен быть **профессиональным** (Business/Creator) и привязан к странице Facebook.
2. [developers.facebook.com](https://developers.facebook.com) → Create app → тип Business →
   добавьте продукты **Facebook Login** и **Instagram Graph API**.
3. Redirect URI: `<PULSE_PUBLIC_URL>/api/oauth/reels/callback`.
4. В `.env`: `META_APP_ID`, `META_APP_SECRET`.

## Шаг 5. Задать тему канала

«Аккаунты → Тема канала». Тема — это не украшение: идеи, сценарии и подбор кадров
строятся вокруг неё, а не вокруг «средней» ниши. Примеры, которые работают:

- «зомби-апокалипсис, выжившие, клаустрофобия, тонкий звук»;
- «разборы инструментов для контента, цифры и эксперименты»;
- «тренировки дома без инвентаря, 20 минут, для новичков».

Канал без темы Pulse помечает блокером: контент будет «средним».

---

## Шаг 6. Добавить то, что продаёте

«Продукты → Добавить». Минимум — ссылка и короткое описание. Три поля, которые важны:

- **URL** — куда ведёт трафик (свой лендинг, Telegram, маркетплейс, CPA-ссылка);
- **Что показывает** — `в видео и описании` / `только в видео` / `только в описании`;
- **Всегда показывать** — по умолчанию действует правило 80/20 (реклама в каждом пятом
  ролике), но для своего продукта можно включить постоянный показ.

Маркировка рекламы при этом остаётся обязательной — отключить её нельзя, это требование
площадок и закон.

## Шаг 7. Сериал (длинный формат = больше денег)

YouTube платит за длинные видео в 2–3 раза лучше Shorts: там включаются mid-roll вставки.

1. «Сериалы → Новый сериал»: жанр, длина серии (8–20 минут), число серий.
2. Библия сериала (мир, герои, правила) — её пишет ИИ, вам достаточно прочитать.
3. Кнопка «Пересобрать ИИ» у серии переписывает текст живым языком.
4. «Озвучить» → «Собрать видео»: фото-ряд (Flux, бесплатно) + субтитры + голос.

Кадры кэшируются по промпту: повторная сборка серии не тратит ни времени, ни лимитов.

---

## Шаг 8. Один клик до денег

«Студия → Включить полный автопилот».

Что произойдёт: включатся ежедневные ролики, публикация серий по расписанию, раздача
кампаний и маркировка; у всех проектов включится автопилот; у сериалов появится запас
из трёх серий. Под кнопкой сразу видно **блокеры** — что мешает заработать прямо сейчас
(не подключён аккаунт, нет продукта, канал без темы).

Через 20–60 минут после этого в очереди появятся первые ролики.

## Шаг 9. Контроль без залипания в панели

Создайте бота в Telegram:

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Напишите своему боту любое сообщение.
3. Узнайте chat id: `curl https://api.telegram.org/bot<ТОКЕН>/getUpdates` (поле `chat.id`).
4. В `.env`:

```
PULSE_TELEGRAM_BOT_TOKEN=123456:AA...
PULSE_TELEGRAM_CHAT_ID=123456789
```

Раз в сутки после 10:00 по вашему часовому поясу придёт сводка: что вышло, просмотры,
клики, деньги, что упало и какие блокеры мешают. «Настройки → Уведомления → Проверить связь» —
тест прямо сейчас.

## Что будет дальше и когда появятся деньги

| Время | Что происходит |
|---|---|
| 0–1 час | первые ролики в очереди, первые публикации |
| 1–7 дней | набирается статистика; Pulse подстраивает часы публикаций и форматы |
| 2–6 недель | первые клики по ссылке и первые продажи/комиссии |
| 1–3 месяца | устойчивый темп, сравнение форматов, рост подписчиков |
| 3+ месяца | канал подходит под требования площадок (1000 подписчиков и 4000 часов для YouTube) |

Честно: без вложений деньги приходят **не от площадок**, а от продукта и интеграций —
потому что выплаты YouTube/TikTok для новых каналов (тем более из РФ) недоступны.
Площадки нужны как источник бесплатного трафика. На экране «Деньги» видно все три канала
и фактическую себестоимость: на бесплатном стеке это около 1 ₽ за ролик (только процессор),
а не 66 ₽ по прайсу платных сервисов.

## Частые вопросы

**Нужно ли платить за ИИ?** Нет. Один бесплатный ключ (NVIDIA, GitHub, Gemini или Groq)
покрывает идеи, сценарии, описания и библию сериала. Озвучка Edge TTS бесплатна всегда.

**Сколько роликов в день?** По умолчанию 2 на проект. Меняется в «Настройках →
Максимум постов в день на аккаунт». Больше 3–4 в день на новом канале — риск.

**Можно не публиковать автоматически?** Да: «Ручная проверка каждого ролика» в настройках.
Ролики будут ждать вашего клика в разделе «Ролики».

**А если сервер выключится?** Очередь переживает рестарт: незавершённые задачи
возвращаются в работу, ничего не теряется.

**Где взять бесплатные картинки?** Уже настроено: Flux через Pollinations без ключа,
с кэшем на диск. Платные провайдеры подключаются только если добавите их ключи.
