# Деплой Pulse: где хостить, сколько это стоит и что нужно для первых денег

Документ отвечает на три вопроса по порядку:

1. **Где запустить** — сравнение площадок, включая вариант «бесплатно и надолго».
2. **Как запустить** — пошагово для Railway, Oracle Always Free и любого VPS.
3. **Когда пойдут деньги** — что технически готово, а что зависит от площадок и вас.

> Нужен самый короткий путь «с нуля до первых денег без вложений»? Он в отдельном документе:
> [`START.md`](START.md) — бесплатные ключи ИИ, бесплатная озвучка, бесплатный публичный адрес,
> регистрация приложений площадок и один клик до автопилота.

---

## 0. Коротко

| Вопрос | Ответ |
|---|---|
| Запускается ли одной кнопкой? | Да: `Dockerfile` + `railway.json` / `render.yaml` / `fly.toml` / `docker-compose.yml` + `deploy/install.sh` для чистого сервера |
| Есть ли бесплатный вариант «навсегда»? | Да — **Oracle Cloud Always Free** (4 ARM-ядра, 24 ГБ RAM, 200 ГБ диска). Требуется карта для верификации, списаний нет |
| Railway бесплатен? | Нет. Пробный кредит $5, дальше Hobby от $5/мес. Удобен для быстрого запуска и проверки |
| Render / Koyeb free? | Бесплатны, но **диск временный** и сервис засыпает: база и ролики пропадут после перезапуска. Только для демонстрации |
| Заработает ли само? | Технически — да, конвейер пишет, озвучивает, рендерит и публикует. Но деньги включаются только в `PULSE_MODE=live`, с реальными ключами и аккаунтами в программах монетизации |

Важно: в `demo`-режиме (он включён по умолчанию) **все цифры симулированы**. В панели теперь
висит честная полоса «Демо-режим: реальных выплат нет» — она исчезает в `live`.

## 1. Сравнение площадок

| Площадка | Цена | Диск | CPU/память | Для сериалов 16:9 | Вердикт |
|---|---|---|---|---|---|
| **Oracle Cloud Always Free** | 0 ₽ навсегда | 200 ГБ (постоянный) | 4 ARM OCPU, 24 ГБ RAM | Рендер 10-минутной серии — единицы минут | **Рекомендую как «бесплатно и навсегда»** |
| Railway | $5/мес (входит $5 кредита), пробный $5 на 30 дней | том 0.15 $/ГБ-мес (Hobby — 5 ГБ) | 1 vCPU / 0.5 ГБ по умолчанию | Отлично, если рендерить по расписанию | Быстрый старт; см. [`RAILWAY.md`](RAILWAY.md) |
| Render (free) | 0 ₽ | **временный** | 0.1 CPU, 512 МБ | Не хватит CPU, диск обнуляется | Только посмотреть интерфейс |
| Render (starter) | от $7/мес + диск | постоянный | 0.5 CPU | Медленно, но жить можно | Если не хочется администрировать |
| Koyeb (free) | 0 ₽ | **временный** | 0.1–0.5 vCPU | То же, что Render free | Демо |
| Fly.io | от ~$3–5/мес | том 3 ГБ | shared 1 ГБ RAM | Нормально для коротких, для серий тесно | Если нужен edge и простой CLI |
| Свой VPS (Hetzner, Aeza и др.) | от ~$4–6/мес | есть | 2 vCPU / 4 ГБ | Хорошо | Когда пошли деньги |

**Что важно именно для Pulse.** Приложение — один Node-процесс + ffmpeg. Оно:
- пишет на диск базу SQLite и медиа → **нужен постоянный диск**, иначе после рестарта всё с нуля;
- рендерит видео в CPU → на 0.1 vCPU бесплатных тарифов серия 10 минут будет собираться часами;
- не требует Postgres/Redis — специально, чтобы жить на одной машине.

**Вывод:** «бесплатно и навсегда» = Oracle Always Free. «Быстро попробовать» = Railway.
«Работает и зарабатывает» = тот же Oracle или VPS за $5, когда появятся первые деньги.

## 2. Railway — быстрый запуск (15 минут)

> Подробный разбор (переменные, том, домен, откаты, разбор сбоев, цифры по деньгам) —
> в отдельном документе: [`RAILWAY.md`](RAILWAY.md). Ниже — самый короткий путь.

```bash
bash deploy/railway.sh
```

Скрипт сам: проверит CLI и вход, создаст проект, сгенерирует `PULSE_SECRET` и `PULSE_PASSWORD`,
перенесёт бесплатные ключи ИИ из `.env`, подключит том к `/app/data`, задеплоит и дождётся
ответа `/api/health`. В конце печатает адрес и пароль.

Руками то же самое:

1. **New Project → Deploy from GitHub repo** → Railway увидит `railway.json` и соберёт `Dockerfile`.
2. **Volumes → Add Volume**, mount path `/app/data`. Без тома база и ролики живут до перезапуска.
3. **Variables**: `PULSE_PASSWORD`, `PULSE_SECRET` (`openssl rand -hex 32`), `PULSE_MODE=demo`,
   `PULSE_TZ=Europe/Moscow`, один бесплатный ключ ИИ + `PULSE_AI=on`.
   `PORT` задавать не нужно. **`PULSE_PUBLIC_URL` тоже не нужен** — адрес берётся из
   `RAILWAY_PUBLIC_DOMAIN` автоматически.
4. **Settings → Networking → Generate Domain** → откройте адрес и войдите паролем.
5. Проверка: **Настройки → Хостинг** — покажет, подключён ли том, не дефолтный ли пароль,
   какой публичный адрес, сколько места на диске. То же в API: `GET /api/deploy/ready`.

Деньги Railway (2026): Hobby $5/мес включает $5 кредита; RAM $10/ГБ-мес, vCPU $20/vCPU-мес,
том $0.15/ГБ-мес. Ограничение тома в Hobby — 5 ГБ, поэтому в проекте включена уборка медиа
(`PULSE_MEDIA_RETENTION_DAYS=14`).

Обновления: `git push` в подключённую ветку или `railway up --detach`. Данные в томе сохраняются.

## 3. Oracle Cloud Always Free — бесплатно навсегда (40 минут)

Это единственный вариант «бесплатно и без срока» с диском и нормальным CPU.

### 3.1. Создать машину

1. Аккаунт [cloud.oracle.com](https://cloud.oracle.com) (нужна карта для верификации; на
   Always Free списаний нет).
2. Регион — ближайший к аудитории (для РФ обычно Frankfurt или Amsterdam).
3. **Compute → Instances → Create instance**:
   - Image: **Ubuntu 24.04** (или 22.04);
   - Shape: **Ampere A1.Flex**, 4 OCPU, 24 ГБ RAM — это и есть Always Free;
   - Boot volume: 50–100 ГБ (входит в 200 ГБ бесплатных);
   - SSH-ключ: загрузите свой публичный ключ.
4. После создания: **Subnet → Security List → Add Ingress Rules**: TCP 80 и 443 (и 8080,
   если хотите открывать панель по IP без домена).

### 3.2. Поставить Pulse одной командой

```bash
ssh ubuntu@<публичный-ip>
curl -fsSL https://raw.githubusercontent.com/ogSulem/pulse/main/deploy/install.sh | sudo bash
```

Скрипт поставит Docker, добавит своп (если RAM мало), склонирует код в `/opt/pulse`,
сгенерирует `.env` со случайным паролем и секретом, соберёт образ и поднимет контейнер.
В конце напечатает пароль входа и адрес.

С доменом и HTTPS:

```bash
sudo PULSE_DOMAIN=pulse.example.com bash /opt/pulse/deploy/install.sh
```

Caddy сам получит сертификат Let's Encrypt (нужен A-запись домена на IP).

### 3.3. Что сделать сразу после

```bash
cd /opt/pulse
sudo docker compose ps                 # контейнер healthy
curl -s localhost:8080/api/health      # {"ok":true,...}
sudo docker compose logs -f pulse      # видно старт, пароль (если сгенерирован), рендеры
```

### 3.4. Ограничение Oracle

Oracle вправе освобождать **простаивающие** Always Free ресурсы (политика idle reclamation).
Практика: держите на машине живую нагрузку (рендеры, регулярные бэкапы) и не удаляйте
инстанс надолго. Если машину всё же освободили — данные восстановите из бэкапа (см. §6).

## 4. Любой VPS с Docker

Минимум: 2 vCPU, 4 ГБ RAM, 20 ГБ диска, Ubuntu 22.04/24.04.

```bash
sudo apt update && sudo apt install -y docker.io docker-compose-v2 git
git clone https://github.com/ogSulem/pulse.git /opt/pulse && cd /opt/pulse
cp .env.example .env && nano .env       # PULSE_PASSWORD, PULSE_SECRET, PULSE_DOMAIN
sudo docker compose up -d --build       # без домена
sudo docker compose --profile tls up -d # с HTTPS через Caddy
```

Скрипт `deploy/install.sh` делает то же самое, но без ручных шагов.

## 5. Переменные окружения

| Переменная | Зачем | По умолчанию |
|---|---|---|
| `PULSE_MODE` | `demo` — симуляция; `live` — реальные площадки и провайдеры | `demo` |
| `PULSE_PASSWORD` | пароль входа в панель | локально `pulse`; на облаке генерируется случайный и печатается в лог |
| `PULSE_SECRET` | подпись сессий + шифрование токенов аккаунтов | генерируется и хранится в `data/.pulse-secret` |
| `PORT` | порт, который передаёт платформа | — |
| `PULSE_PORT` | порт для docker compose | `8080` |
| `PULSE_DATA_DIR` | каталог данных (база, медиа, бэкапы) | `./data` |
| `PULSE_DB_PATH` | путь к SQLite | `<data>/pulse.db` |
| `PULSE_MEDIA_DIR` | путь к готовым файлам | `<data>/media` |
| `PULSE_PUBLIC_URL` | публичный адрес; нужен Instagram для забора видео | — |
| `PULSE_TZ` | часовой пояс расписания | `Europe/Moscow` |
| `PULSE_RENDER_QUALITY` | `high` / `balanced` / `fast` | `high` |
| `PULSE_RENDER` | `off` отключает рендер (экономия CPU на слабом хосте) | `on` |
| `PULSE_FFMPEG_PATH` | свой бинарь ffmpeg | резолвится автоматически |

Ключи провайдеров (`NVIDIA_API_KEY`, `GEMINI_API_KEY`, `GROQ_API_KEY`, `RUNWAY_API_KEY`, …) нужны только
в `live`. Полный список — в `.env.example`.

### Как запустить без вложений

Всё, что нужно для старта, бесплатно. Платить придётся только за хостинг, если не
брать бесплатный уровень (ниже — как его взять).

| Что | Бесплатное решение | Что даёт |
|---|---|---|
| Тексты | NVIDIA NIM, GitHub Models, Gemini, Groq | идеи, сценарии, описания, библия сериалов |
| Озвучка | Edge TTS (`TTS_PROVIDER=edge`) | нейронные голоса, любая длина, 0 ₽ |
| Кадры | Pollinations Flux (без ключа) | нейро-фото-ряд серий |
| Хостинг | Oracle Cloud Always Free (ARM, 4 OCPU / 24 ГБ) или локальный ПК | контейнер с томом данных |
| Публичный адрес | `bash deploy/tunnel.sh` (Cloudflare Quick Tunnel) | https-ссылка для Instagram и OAuth |
| Деньги | свой продукт по ссылке + бренд-кампании | продажи и оплата за размещения |

**Бесплатный публичный адрес (нужен для Reels).** Instagram публикует не файл, а ссылку:
площадка сама скачивает видео. Поэтому:

```bash
docker compose up -d          # панель на 8080
bash deploy/tunnel.sh         # выдаст https://xxx.trycloudflare.com
# вписать в .env: PULSE_PUBLIC_URL=https://xxx.trycloudflare.com
docker compose up -d          # перезапустить с новым адресом
```

Скрипт скачивает официальный `cloudflared` одним файлом (аккаунт не нужен) и печатает
готовые redirect URI для кабинетов разработчика. Туннель живёт, пока открыт терминал.
Для постоянного адреса нужен домен и профиль Caddy (`docker compose --profile tls up -d`).

**Проверка, что снаружи всё видно.** «Создать → Студия → Проверить публичный адрес» делает реальный
запрос по `PULSE_PUBLIC_URL` снаружи и проверяет не только панель, но и отдачу `/media`:
именно туда смотрит Instagram. Локальный `curl` эту проверку не заменяет — он ходит изнутри.

**Один клик до денег.** «Создать → Студия → Включить полный автопилот» ставит `autopilot_global=1`,
автопубликацию серий, раздачу кампаний и маркировку, включает `autopilot` у всех проектов и
поднимает запас серий до трёх. Там же показываются блокеры: не подключён аккаунт, нет продукта,
нет темы у канала — то есть ровно то, что мешает заработать.

**Сводка в Telegram (бесплатно).** Создайте бота у `@BotFather`, узнайте свой `chat_id`
(`curl https://api.telegram.org/bot<ТОКЕН>/getUpdates` после сообщения боту) и добавьте в `.env`:

```
PULSE_TELEGRAM_BOT_TOKEN=123456:AA…
PULSE_TELEGRAM_CHAT_ID=123456789
```

Дальше «Настройки → Уведомления → Проверить связь». Сводка приходит раз в сутки после 10:00
по часовому поясу панели: вышло роликов, просмотры, клики, деньги (кампании и продажи), что в
расписании, что упало и какие блокеры мешают заработать. Повторная отправка — не чаще раза в
20 часов, поэтому рестарты контейнера не спамят.

**Себестоимость по факту.** На бесплатном стеке (Edge TTS + Pollinations + NVIDIA) производство
ролика стоит примерно 1 ₽ условного CPU, а не 66 ₽ по прайсу платных сервисов — экран «Деньги»
считает прибыль честно. Если вы платите за инфраструктуру, поставьте `powered_by_me = 1`
в настройках, и расчёт вернётся к прайсу.

**Чего бесплатно не будет.** Выплаты YouTube/TikTok недоступны для аккаунтов из РФ
(TikTok Creator Rewards работает в 8 странах, YouTube-партнёрка требует страну выплат).
Реальные деньги без вложений на старте дают: продажа своего продукта по ссылке с UTM,
партнёрские/CPA-ссылки и бренд-интеграции. Платформа считает все три канала: клики,
конверсии, начисления по кампаниям — на экране «Деньги».

### ИИ на бесплатных лимитах

| Что | Чем закрывается | Цена |
|-----|-----------------|------|
| Идеи, сценарии, описания, библия сериала | NVIDIA NIM (`meta/llama-3.3-70b-instruct`), фолбэки Gemini / Groq / Cerebras / OpenRouter | 0 ₽, ~40 запросов/мин у NVIDIA |
| Озвучка (в т.ч. 15-минутная серия) | `TTS_PROVIDER=edge` — голоса Microsoft `ru-RU-DmitryNeural` / `SvetlanaNeural` | 0 ₽, без ключа |
| Фото-ряд сериала | Flux через Pollinations (без ключа) или Cloudflare Workers AI | 0 ₽ |
| Видео | NVIDIA Cosmos по тому же ключу; платные Runway/Luma/Pika — опционально | 0 ₽ в рамках ключа |

Что действительно нужно открыть в фаерволе, помимо HTTPS наружу:

- `integrate.api.nvidia.com`, `ai.api.nvidia.com` — LLM и видео NVIDIA;
- `speech.platform.bing.com` (WSS, 443) — бесплатная озвучка Edge;
- `image.pollinations.ai` — нейро-кадры;
- `graph.facebook.com`, `open.tiktokapis.com`, `www.googleapis.com` — публикация.

Если сервер за жёстким NAT, озвучка сама откатится на системный синтез, а тексты — на Content Brain:
платформа продолжит работать, но без «живого» ИИ. Проверка — «Настройки → ИИ-движок → Проверить ИИ».

**Безопасность на публичном адресе:**
- задайте `PULSE_PASSWORD` — иначе на облаке пароль генерируется и показывается в логах деплоя;
- не публикуйте панель без пароля: внутри лежат токены аккаунтов (они зашифрованы AES-256-GCM
  ключом из `PULSE_SECRET`);
- вход ограничен 12 попытками в минуту с одного IP;
- токены сессий живут 14 дней, «Выйти» в панели стирает токен в браузере.

## 6. Данные, бэкапы, переезд

Всё состояние — в одном каталоге (`/app/data` в контейнере):

```
data/
├─ pulse.db          # SQLite: проекты, аккаунты, ролики, серии, деньги, логи
├─ pulse.db-wal      # журнал SQLite
├─ media/            # готовые mp4, обложки, озвучка
├─ backups/          # дампы базы
├─ .pulse-secret     # секрет подписи (не теряйте: иначе токены аккаунтов не расшифруются)
└─ first-login.txt   # пароль, если он был сгенерирован автоматически
```

Бэкап базы (консистентный, без остановки сервиса):

```bash
docker compose exec pulse npm run backup              # последние 14 копий
docker compose exec pulse npm run backup -- --keep 30 # хранить 30
```

В cron на хосте (каждый день в 04:00):

```bash
0 4 * * * cd /opt/pulse && /usr/bin/docker compose exec -T pulse npm run backup >> /var/log/pulse-backup.log 2>&1
```

Медиа в дамп не входит — это отдельные файлы. Если ролики нужны после переезда:

```bash
tar czf pulse-media-$(date +%F).tgz -C /opt/pulse/data media
```

Переезд на другую машину: скопировать каталог `data` целиком (вместе с `.pulse-secret`),
развернуть там код и запустить compose. Ничего в базе править не нужно.

## 7. Обновления

```bash
cd /opt/pulse && sudo bash deploy/install.sh     # git pull + пересборка + рестарт
```

База мигрируется сама при старте (`migrate()` + `ensureColumns()`), данные не теряются.
Перед обновлением на всякий случай: `docker compose exec pulse npm run backup`.

## 8. Чек-лист приёмки после деплоя

- [ ] `GET /api/health` → `{"ok":true,"mode":"demo"}` (или `"live"`).
- [ ] Панель открывается по HTTPS, вход работает, «Выйти» возвращает на логин.
- [ ] `GET /api/transparency` → в ответе `render.available: true`, `render.ffmpegSource` (системный или installer).
- [ ] «Рост» → «Студия» → собрать ролик: файл появляется в `/media/...` и играется в браузере.
- [ ] Перезапуск контейнера не стирает данные: после `docker compose restart` ролик и аккаунты на месте.
- [ ] Том подключён (`docker volume ls`, в Railway/Render — раздел Volumes).
- [ ] Бэкап создаётся: `npm run backup` → файл в `data/backups`.
- [ ] В `demo` видна честная полоса «Демо-режим», в `live` — нет.

## 8.5. Вход в каналы (OAuth) и нейро-кадры — что заполнить один раз

Порядок такой: развернуть → открыть **Студия** → она сама покажет, чего не хватает.
Ниже — то же самое текстом, без интерфейса.

**1. Домен.** `PULSE_PUBLIC_URL=https://ваш-домен` — из него собираются redirect URI и
публичные ссылки на видео (Instagram забирает файл по URL).

**2. Приложения площадок.** Заводить нужно один раз, дальше вход — одной кнопкой.

| Площадка | Где создавать | Redirect URI в кабинете | Переменные |
|---|---|---|---|
| YouTube | console.cloud.google.com → Credentials → OAuth client (Web) | `https://домен/api/oauth/youtube/callback` | `YOUTUBE_CLIENT_ID`, `YOUTUBE_CLIENT_SECRET` |
| TikTok | developers.tiktok.com → Content Posting API | `https://домен/api/oauth/tiktok/callback` | `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET` |
| Instagram | developers.facebook.com → Instagram Graph API | `https://домен/api/oauth/reels/callback` | `META_APP_ID`, `META_APP_SECRET` |

Точный redirect URI всегда показывает сама панель: «Аккаунты» → «Войти и подключить» или
«Студия» → «Вход в каналы». Если домен не задан, подставится текущий адрес панели.

**3. Нейро-кадры.** Ничего покупать не нужно: по умолчанию `pollinations` (Flux, без ключа,
~15 с между кадрами, анонимно). Хотите быстрее и без водяного знака — добавьте
`CLOUDFLARE_ACCOUNT_ID` + `CLOUDFLARE_AI_TOKEN` (10 000 нейронов в день бесплатно), Pulse
переключится на Workers AI сам. Кадры кэшируются в `data/media/frames` — повторный рендер
серии не тратит лимиты. В `demo` нейро-кадры включаются только при `PULSE_IMAGES=on`.

**4. Тема канала.** В карточке аккаунта заполните «Тема канала» — по ней пишутся сценарии
и подбираются идеи. Один канал = одна тема: «зомби-истории», «нейро-разборы», «мой продукт».

**5. Продукт.** «Продвижение» → «Где показывать»: в видео, в описании или везде, и галочка
«в каждом ролике», если продавать нужно постоянно (маркировка рекламы остаётся).

**6. Автопилот.** «Сериалы» → «Автопилот сериала»: «писать серии заранее» (ряд вперёд 1–6) и
«собирать видео без меня». С включённым вторым пунктом студия выпускает серию сама:
сценарий → озвучка → нейро-кадры → mp4 → расписание.

## 9. Путь к первым деньгам (честно)

**Что уже делает платформа:** пишет сценарии и описания, собирает видео и обложки, озвучивает,
публикует по расписанию, ведёт аналитику, считает деньги и окупаемость, блокирует публикацию
без маркировки рекламы/ИИ и без erid, собирает сериалы 16:9 с плейлистами и нарезками.

**Что нельзя обойти кодом:**

1. **`PULSE_MODE=live` и реальные ключи.** В `demo` площадки не вызываются — постинг
   симулируется. Нужны свои ключи провайдеров (текст, озвучка, видео) и OAuth-приложения
   площадок.
2. **Аудированные приложения.** Google: без аудита проекта загрузки на YouTube уходят только
   приватными (в панели есть переключатель «Проект Google прошёл аудит»). TikTok: неаудированный
   клиент публикует только `SELF_ONLY` и не более чем на 5 креаторов в сутки.
3. **Пороги монетизации.** YouTube: 1000 подписчиков + 4000 часов просмотра за 90 дней
   (ранний доступ: 500 подписчиков + 3000 часов) или 10 млн просмотров Shorts за 90 дней.
   TikTok Creator Rewards: 10 000 подписчиков + 100 000 просмотров за 30 дней, видео > 1 мин,
   и программа работает не во всех странах (РФ в списке нет).
   Instagram-бонусы — только по приглашению.
4. **Правила оригинальности.** С 2025–2026 YouTube разделяет `inauthentic content` на категории:
   шаблонные повторы, манипулятивные формулы, ИИ-персоны в чувствительных темах. ИИ сам по себе
   не запрещён, запрещён конвейерный шаблон. Поэтому в Pulse есть аудит оригинальности серии
   (сравнение с соседними сериями) — он блокирует дословные повторы.
5. **Маркировка.** Синтетический голос и ИИ-кадры помечаются как «altered or synthetic content»;
   реклама в РФ — «Реклама» + данные рекламодателя + erid. Pulse вставляет это в описание и
   останавливает публикацию без маркировки, но галочку в YouTube Studio ставит человек.
6. **Налоги и юрлицо.** Выплаты приходят на аккаунт площадки; в РФ это доход, который нужно
   декларировать. Это вне кода.

**Реалистичный горизонт:** 2–6 недель на первый регулярный контент и живые просмотры,
3–6 месяцев до порогов YPP при еженедельных сериях и ежедневных нарезках. Сериалы дают
RPM в 6–20 раз выше Shorts, но требуют дисциплины выпуска — именно поэтому в v8.2 появился
автоматический выпуск по расписанию.

## 10. Если что-то не поднялось

| Симптом | Причина | Что делать |
|---|---|---|
| Контейнер перезапускается | не хватает прав на `data` | `sudo chown -R 1000:1000 data` |
| `exec /usr/local/bin/docker-entrypoint.sh: No such file or directory`, код 127 | файл склонирован с CRLF (Windows, `core.autocrlf=true`): в shebang попал `\r`, и ядро ищет `/bin/sh\r` | `sed -i 's/\r$//' docker-entrypoint.sh` и `docker compose up -d --build`; с v15 образ нормализует entrypoint сам, а `.gitattributes` держит LF. Проверить все скрипты: `sed -i 's/\r$//' deploy/*.sh` |
| `health` не отвечает | приложение слушает не тот порт | проверьте `PORT`/`PULSE_PORT`, оба поддержаны; `docker compose logs pulse` покажет, на какой порт встал сервис |
| Рендер пишет «ffmpeg недоступен» | нет бинаря в образе | образ v8.2+ ставит системный ffmpeg; локально `brew install ffmpeg` или `PULSE_FFMPEG_PATH` |
| После рестарта пустая база | нет постоянного диска (Render/Koyeb free) | подключите volume или переезжайте на Oracle/VPS |
| Пароль неизвестен | он был сгенерирован при первом старте | `docker compose logs pulse \| grep Пароль` или `cat data/first-login.txt` |
| Токены аккаунтов «не расшифровываются» | потерян `data/.pulse-secret` | подключите аккаунты заново или восстановите секрет из бэкапа |
